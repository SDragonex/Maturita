## Co vysvětlit u zkoušky

HTML určuje význam a strukturu obsahu, CSS jeho vzhled a rozložení. Dokument obsahuje hlavičku s metadaty a tělo. Nadpisy vyjadřují hierarchii; odkaz slouží k navigaci a tlačítko k akci. Formulář potřebuje popisky a srozumitelnou validaci. Box model tvoří obsah, padding, border a margin. Kaskáda kombinuje původ pravidel, důležitost, vrstvy a specificitu; při jinak shodné přednosti rozhoduje pořadí. Flexbox uspořádává obsah převážně v jednom rozměru, Grid ve dvou. Responzivní stránka se přizpůsobuje prostoru bez ztráty obsahu.

## Praktický příklad

Vytvoř stránku se záhlavím, navigací, hlavním obsahem a patičkou. Použij jeden hlavní nadpis a logické podnadpisy. Seznam témat zobraz jako mřížku, na úzkém displeji jako jeden sloupec. Ověř ovládání odkazů tabulátorem.

## Časté chyby

Nevytvářej tlačítko jen z klikatelného div. Pevná šířka může způsobit vodorovný posun celé stránky.
