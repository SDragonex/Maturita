## Jak dokumentaci udržovat

Po změně pravidel oprav průvodce i související plán a připiš datum kontroly zdroje. Po změně postupu sestavení oprav README i údržbu. Výsledky testů uváděj do protokolu až po jejich provedení; odliš technickou kontrolu, věcnou revizi a potvrzení školou.

Školní PDF uložená v projektu jsou pro rok 2026. Dokud nejsou nahrazena doloženými podklady 2027, nepřejmenovávej je ani jejich stav na „ověřeno pro 2027“.
